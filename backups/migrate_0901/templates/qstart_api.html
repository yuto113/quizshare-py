はじめに

Qstart APIを使うと、yutoが作ったAIモデルを自分のアプリから呼び出せます。

認証

すべてのAPIリクエストにはAPIキーが必要です。ダッシュボードで発行できます。

# リクエストヘッダーにAPIキーを含める
Authorization: Bearer qsk_あなたのAPIキー

エンドポイント

POST/qstart/api/v1/chat

AIとチャットします。

# リクエスト
{
  "message": "AIとは何ですか？",
  "model": "equi-1"
}

# レスポンス
{
  "model": "equi-1",
  "message": "人工知能のことで、コンピュータが人間のように考える技術です",
  "tokens_used": 42
}

GET/qstart/api/v1/models

利用可能なモデルの一覧を取得します。

GET/qstart/api/v1/usage

今月の使用量を確認します。

API専用

採点API

POST/qstart/api/v1/grade

答え合わせをします。表記ゆれや言い換えもAIが判定します。

{
  "question": "日本の首都は？",
  "correct": "東京",
  "answer": "とうきょう"
}

返り値:

{
  "ok": true,
  "verdict": "正解",
  "reason": "ひらがなですが同じ場所です。",
  "stage": 4,
  "by": "voto"
}

verdict は「正解」「部分正解」「不正解」のいずれか。stage はどの段階で判定したか（1=完全一致 / 2=表記ゆれ / 3=別解 / 4=AI）。

Python サンプルコード

import requests

response = requests.post(
  "https://yuto113.pythonanywhere.com/qstart/api/v1/chat",
  headers={"Authorization": "Bearer qsk_あなたのキー"},
  json={"message": "こんにちは", "model": "equi-1"}
)

print(response.json()["message"])
